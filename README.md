# Portfolio React Glass

A standalone React/Vite rebuild of Aarushi Nema's portfolio with an Apple-inspired glass interface and light/dark mode.

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:5174`.

## Build

```bash
npm run build
```

## Notes

This is intentionally separate from the Quarto portfolio repository. Copy final links or deployment URLs back into the Quarto site only when needed.
